# 🚀 RAG Chatbot (DocBase)

A full-stack RAG (Retrieval-Augmented Generation) chatbot built with **FastAPI + JavaScript + PostgreSQL**.

---

## Features

* User Login & Signup (JWT)
* Upload Documents (PDF, DOCX, TXT)
* AI Chat based on documents
* Chat History per user


---

## Tech Stack

* Backend: FastAPI, PostgreSQL, LangChain, FAISS
* Frontend: HTML, CSS, JavaScript
* LLM: Groq / OpenAI

---

## Setup

```bash
git clone https://github.com/your-username/rag-app.git
cd rag-app/backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Open:

```
frontend/login.html
```
